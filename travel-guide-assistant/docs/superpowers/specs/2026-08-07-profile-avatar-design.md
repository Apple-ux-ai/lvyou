# 个人资料头像扩展设计

## 背景

个人中心当前已经支持昵称和邮箱编辑，但头像只显示固定的“旅”字，资料信息较少。本次扩展采用已确认的 A 方案：紧凑资料卡，在不改变现有 Tab 结构的前提下增加真实头像编辑能力。

## 目标

- 在个人中心顶部展示用户头像、昵称、邮箱和现有统计信息。
- 在“编辑资料”弹窗中选择、预览、移除本地头像。
- 未设置头像时使用昵称首字作为稳定回退显示。
- 头像只保存在当前浏览器，不上传后端，不改变行程 API。

## 组件与数据流

- `ProfileHero` 接收 `user.avatar`，有值时渲染图片，否则渲染昵称首字。
- `EditProfileDialog` 增加图片选择、预览、移除和保存状态。
- `App.handleProfileSave` 继续通过 `TravelMate.utils.setSession` 写入 `travelmate-user`，扩展字段为 `avatar`。
- 上传图片在浏览器端通过 `FileReader` 和 `canvas` 压缩为小尺寸 Data URL，再写入本地会话。

## 交互与校验

- 点击“编辑资料”打开弹窗，显示当前头像或首字回退。
- 仅接受图片文件；文件超过 5MB、读取失败或压缩失败时显示行内错误，并保留旧头像。
- “移除头像”清空草稿头像；“取消”丢弃所有草稿修改。
- 保存成功后关闭弹窗，顶部头像立即更新并显示“个人资料已保存”。
- 上传、移除和关闭按钮提供明确的可访问名称，输入控件支持键盘操作。

## 测试范围

- 合同测试检查头像字段、回退逻辑和编辑控件存在。
- Playwright 覆盖未上传回退、有效图片预览、刷新后持久化、移除、无效文件错误和取消不保存。
- 在桌面和移动视口检查资料卡不溢出，并确认无新增控制台错误。

## 非目标

本次不接入头像上传 API、云端图片存储、裁剪编辑器、社交头像同步或完整用户资料页重构。
