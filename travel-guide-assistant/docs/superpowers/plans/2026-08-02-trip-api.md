# Trip API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add in-memory trip creation and retrieval endpoints for the assistant save flow.

**Architecture:** `Trip` extends the existing itinerary response shape with an ID. `TripStore` owns process-local state, while FastAPI routes validate requests and map a missing record to HTTP 404.

**Tech Stack:** Python 3, FastAPI, Pydantic v2, httpx, pytest-asyncio.

### Task 3: Expose Trip Routes

**Files:**
- Modify: `backend/app/main.py`
- Test: `backend/tests/integration/test_trips_api.py`

- [x] **Step 1: Add routes**

```python
@app.post("/api/trips", response_model=Trip, status_code=201)
async def create_trip(itinerary: Itinerary) -> Trip:
    return trip_store.create(itinerary)

@app.get("/api/trips/{trip_id}", response_model=Trip)
async def get_trip(trip_id: str) -> Trip:
    trip = trip_store.get(trip_id)
    if trip is None:
        raise HTTPException(status_code=404, detail="Trip not found")
    return trip
```
